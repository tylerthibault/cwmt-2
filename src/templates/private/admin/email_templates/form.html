Template Variables

Use these variables in your subject and body text. They will be replaced with actual values when the email is sent.

💡 Tip: Click on a variable to insert it into the HTML editor!

Common Variables:
  • {user_name} - User's full name
  • {user_email} - User's email address
  • {app_name} - Application name
Action-Specific Variables:

Check the action's "Available Variables" in the Email Actions table to see which variables are available for each action.

💡 Workflow:
  1. Write your email in the HTML editor
  2. Click "Generate from HTML" to create plain text version
  3. Preview before assigning to an action
✨ Pro Tip: The plain text version is auto-generated from your HTML, so you don't have to write it twice!
